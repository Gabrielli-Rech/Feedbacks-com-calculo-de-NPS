## 📊 Feedbacks com Cálculo de NPS

Uma aplicação simples para calcular o Net Promoter Score (NPS) a partir de feedbacks de clientes. Ideal para empresas que desejam medir a satisfação e lealdade de seus consumidores de forma prática e eficiente.

## 🚀 Funcionalidades

Entrada de Feedbacks: Permite que usuários insiram feedbacks com notas de 0 a 10.

Cálculo Automático de NPS: Calcula automaticamente o NPS com base nas notas fornecidas.

Classificação de Clientes: Classifica os clientes em Promotores, Neutros ou Detratores.

Exibição de Resultados: Mostra o NPS final e a porcentagem de cada categoria de cliente.
